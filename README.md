# Traoré Caisse Scanner

Application de caisse pour magasin : scan des codes-barres avec la caméra, panier, total, paiements (espèces, Mobile Money, crédit), stock, clients et dettes, reçus, dépenses et rapports.

Conçu par **Aboubacary Traoré**.

## Obtenir l'APK
Chaque envoi sur `main` construit l'APK automatiquement (onglet **Actions**). Le fichier se télécharge dans l'onglet **Releases**.

## Signature
Pour pouvoir installer les mises à jour par-dessus l'ancienne version, ajoutez ces secrets (Settings → Secrets and variables → Actions) :
`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
